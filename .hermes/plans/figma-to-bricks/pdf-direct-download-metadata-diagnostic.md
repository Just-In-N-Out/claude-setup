## Smallest proposed architecture

Add one read-only collector and one small panel controller, wired into existing messages. No new plugin, dependency, service, schema migration, converter stage, network endpoint, global diagnostic registry or retained historical snapshots.

### Safe boundary and interfaces

**Proposed new files** (none exist or are written by this plan):

- `src/shared/link-metadata.ts`: closed report/request/reply types only.
- `src/plugin/extract/link-metadata.ts`: synchronous projection over captured selection plus one owning-plugin list-store read.
- `src/ui/link-metadata.ts`: button/report/status/request ownership; no upload/copy/save imports.

The following is a contract fragment, not implementation or a claim of tested behavior. The shared report types must define the closed fields in the table below; no index signatures, arbitrary `unknown` report bodies, raw node/store objects or credential/settings objects.

```ts
export type MetadataReadApi = Readonly<{
  readLists: () => string;
}>;
export type MetadataRequest = Readonly<{
  type: "inspectLinkMetadata";
  requestId: string;
}>;
export type MetadataFailureCode =
  | "empty-selection" | "removed-source" | "read-failed"
  | "limit-exceeded" | "invalid-request";
export type MetadataReply<Report> =
  | Readonly<{ type: "linkMetadata"; requestId: string; report: Report }>
  | Readonly<{ type: "linkMetadataError"; requestId: string; code: MetadataFailureCode }>;
```

- In `plugin/main.ts`, validate the fixed message shape/requestId before touching source. Ignore uncorrelatable malformed requests rather than echoing arbitrary request objects. Capture `selection().slice()` once, plus the last `converted` **IDs only**, without assigning `converted`. Inject `{readLists: () => api.fileData(LISTS_KEY)}` into the collector; no storage reads, other document keys or write-capable API enters it. Handle the new branch's exceptions inside that branch, replying with a fixed diagnostic failure code; never let source/store exceptions reach the existing outer `console.error(e)` or generic conversion/debug error route. Test that boundary with a throwing getter whose exception contains a secret canary.
- Collector signature: `readLinkMetadata(api: MetadataReadApi, selected: readonly MetadataSourceNode[], provenance: MetadataProvenance): MetadataReadResult`. `MetadataSourceNode` exposes only the explicitly read properties/children plus `getStyledTextSegments?(fields: string[]): readonly unknown[]`; no generic property index, clone/remove/export or writer capability. `MetadataProvenance` contains BUILD, captured time, current selection IDs and last-converted IDs, not runtime bundle hashes or source file names.
- Keep collection synchronous; no `await`, component/target lookups, conversion, exports or network. This prevents JavaScript task interleaving while source/list facts are assembled; it does **not** claim an atomic historical Figma revision or defeat collaborator edits. Record start/end time and read gaps. Getter failures become fixed codes, never raw exceptions that might expose text or credentials.
- Traverse all selected roots in order; deduplicate overlapping descendants by source ID while retaining each root's path/reference. Include hidden descendants with a visibility flag rather than silently turning hidden source into absent source. Do not walk parent siblings, other pages, component libraries or prototype targets. An external target gets ID/type only and `not-inspected`.
- Proposed bounds: 10000 distinct nodes, depth 128, report size 2 MiB UTF-8. These are diagnostic safety limits, not existing product limits or proven sufficient for this page. Check them explicitly; return `limit-exceeded` without posting a partial report as complete, without auto-selection changes, retries, pruning or raising the bounds. Builder verifies host-compatible byte sizing. An oversized real case needs a new scoped decision, not silent narrowing.
- Do not use generic JSON serialization of live Figma objects, `plainValue` on arbitrary objects, getters outside the closed projection or a raw object spread. Assemble fresh primitive/array records; stringify only the already-redacted report.

### Privacy-minimal report schema / data classification

| Section | Keep | Exclude / limit |
|---|---|---|
| Provenance | schema discriminator `f2b-link-metadata`, version 1, BUILD, captured times, current selection IDs, last-converted IDs/null, same-ID-set boolean, `basis:current-source`, `historicalInputAvailable:false`, `fullReplaySupported:false` | No Figma file key, document/page names, file paths, user/account identity, runtime-byte identity claim or invented conversion ID. Same IDs do not prove unchanged source. |
| Source topology | source ID, type, parent ID within scope, ordered child IDs, selected-root membership/path, visibility, removed/read-gap flags | No raw names, annotations, pluginData maps, alt descriptions, componentProperties, arbitrary keys or whole scene dumps. |
| Structural facts | finite box/transform values; layout mode/sizing/positioning, padding/gap/align; mask/clip flags; paint **type, visibility, opacity and solid alpha only**, stroke widths; native vector/shape/instance type | No image/video hashes, bytes, SVG/vector paths, colors/styles/fonts libraries, image dimensions fetch, effects/animation payloads or exports. | Text facts | length, newline presence, local equality token, font size, finite line-height unit/value, align/autoresize, `isDownloadLabel` result from the existing pure helper; segment start/end, URL/node-link descriptors and true/false/absent action intent | No characters, raw label strings, font family/style names, raw segment objects or text SVG. Use the same ephemeral equality-token table across link occurrences in source and selected list assignments. Exact raw-string equality is preserved; also record a separate equality token for the result of `safeUrl` when accepted, so trimming/classification does not silently conflate raw and accepted values. Dispose of local references naturally when the call returns; do not persist dictionaries or add cleanup that deletes nodes/files. In-memory source text/store values are necessary reads, not material to export. Do not log them even on a failure.

**Why this is useful despite redaction:** it reveals actual source IDs/structure, saved list owner → button owner mapping, missing/dangling assignments, direct-vs-run links, ordered action intent, image/vector/mask signals and exact classifier outcomes/equality at capture time. It can distinguish a current missing assignment or non-PDF source link from a present eligible-looking store assignment. It deliberately cannot reproduce all normalise/understand heuristics, row filename matching, component inheritance, SVG line-break measurements or the historical emit decision. If the report does not discriminate the next boundary, stop and scope the smallest additional read-only evidence; do not build a speculative behavior fix.
