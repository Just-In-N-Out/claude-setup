### Typed fact and source identity

Add a small shared pure model in **`src/core/model/picture-alpha.ts`**; keep it independent of DOM, Figma, uploads and CSS. Use one versioned discriminated union, not a mandatory boolean or optional truthy object:

```ts
// Planned contract; names may be used verbatim. All numeric fields finite integers.
export type AlphaSide = "top" | "right" | "bottom" | "left";
export type PictureAlpha =
  | { version: 1; state: "measured"; width: number; height: number;
      minAlpha: number; maxAlpha: number; inset: number;
      clearRun: Record<AlphaSide, number> }
  | { version: 1; state: "unknown";
      reason: "unavailable" | "decode" | "budget" | "timeout" | "ambiguous" };
export type PictureAlphaSource =
  | { kind: "fill"; hash: string; width: number; height: number }
  | { kind: "render"; nodeId: string; width: number; height: number;
      scale: number; asPainted: false; imageHashes: readonly string[] };
export interface PictureAlphaRecord {
  source: PictureAlphaSource;
  alpha: PictureAlpha;
}
// Add to Snapshot: pictureAlpha?: Record<string, PictureAlphaRecord>.
// Add to Scene: pictureAlpha?: ReadonlyMap<string, PictureAlphaRecord>.
// PictureContext lookup: alpha(key: string): PictureAlphaRecord | undefined.
```

`clearRun[side]` is the longest contiguous near-clear run in that side's middle half that is clear **both at the border and throughout the defined inward strip**, not a count anywhere in the picture. `minAlpha/maxAlpha` describe all inspected pixels. A missing record is unknown, never inferred opaque or cut-out. Invalid/version-unknown/unbound records become unknown, never refuse the whole otherwise valid debug file. Normalise recomputes admission from validated evidence; no trusted `cutout: true` wire shortcut.

**Proposed conservative policy v1 (A1):** use original decoded resolution without rescaling; near-clear alpha≤8; strip depth `max(2, ceil(min(width,height) × 0.005))`; examine the middle50% of each side; require a continuous run≥`max(4, ceil(sideLength × 0.05))` on **at least two distinct sides**, and some visible source content (`maxAlpha ≥128`). Too-small dimensions to measure the strip/middle/run reliably are unknown. This rejects corner-only rounded photographs, isolated transparent pixels, one-pixel clear/AA frames, uniform50% opacity, fully transparent images and interior-only holes. This is a conservative border-evidence policy, **not semantic recognition of an object**; a source file with substantial clear padding really has transparency even if it depicts a rectangular photo. Marginal/one-sided cut-outs may retain main. Calibrate positives/negatives and the real orange media in Task3 before freezing; if the reported asset fails, preserve the failure and ask about a separately scoped policy—not special-case its pixels/name or relax thresholds silently.
