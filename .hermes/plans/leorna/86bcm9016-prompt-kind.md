### 4.4 Security (security-best-practices, untrusted pack content)

- File names come only from the slug rule → no traversal, no spaces, no `<`/`>`, case-collision safe; `nativewrite` still enforces containment, symlink refusal, staging and rollback.
- The description is JSON-quoted (same technique as `RenderSkill`), so it cannot add frontmatter keys such as `allowed-tools` (test CL-3e). The body follows our closed frontmatter, so a body starting with `---` is content, not frontmatter.
- Bodies keep the shared 64 KiB bound on both sides; warnings name the item and tool only, never body text.
- Pre-existing, not changed here: Claude Code runs ``!`cmd` `` lines in skills/commands when the user invokes them. A prompt can do nothing a synced skill cannot already do; recorded as `found_else` F1 for a policy follow-up (related to 86bcm945q "approved for scripts").
- Tenant isolation, admin role, CSRF and desktop bearer scope are untouched; the publish→serve test re-asserts member 403 and cross-tenant 403 with no prompt text leaked.

### 4.5 Contract compatibility (api-contract-drift-guard)

- Classification: **additive enum value** on two response schemas; for strict consumers it is behavioural. Today's desktop client rejects the whole bundle on an unknown kind (`invalid_bundle`, no files changed). Exposure starts only when an admin assigns a version containing a prompt (seed 1.2.0 or an edited version); existing assignments stay on 1.1.1.
- Rollout: open both PRs together; Justin merges the control-plane PR, then the client PR immediately (the 86bcm902h precedent merged 5 s apart); do not assign a prompt-containing version to real teams until desktop clients are on the merged client. Contract diff artifact saved as `evidence/86bcm9016/contract-diff-<cp-sha7>.txt`.
- No compatibility flag or versioned endpoint (pilot scale, fail-closed old clients, reversible).

package toolconnector

import (
	"fmt"
	"sort"
	"strings"

// PromptName returns the name a tool gives a prompt's command file. A tool
// names the command after its file, so the name follows the skill-folder rule.
func PromptName(item PackItem) (string, error) {
	if item.Kind != PackKindPrompt {
		return "", fmt.Errorf("%w: pack item %q is not a prompt", ErrInvalid, item.Name)
	}
	if len(item.Name) > maxSkillNameBytes || !skillName.MatchString(item.Name) {
		return "", fmt.Errorf("%w: prompt name %q must be lowercase letters, digits and hyphens", ErrInvalid, item.Name)
	}
	if strings.TrimSpace(item.Body) == "" {
		return "", fmt.Errorf("%w: prompt %q needs a body", ErrInvalid, item.Name)
	}
	return item.Name, nil
}

// SkippedPromptWarnings returns one sorted, visible warning per prompt a tool
// cannot install, naming the reason. Sync records it in the run log.
func SkippedPromptWarnings(pack Pack, toolID ToolID, reason string) []string {
	warnings := make([]string, 0)
	for _, item := range pack.Items {
		if item.Kind == PackKindPrompt {
			warnings = append(warnings, fmt.Sprintf("prompt %q is not installed for %s: %s; skipped", item.Name, toolID, reason))
		}
	}
	sort.Strings(warnings)
	return warnings
}

// Claude Code documents .claude/commands/ as the older format that keeps
// working, and a skill of the same name wins over the command.
const commandsDir = ".claude/commands/"

// renderPrompt writes a prompt as a user-invoked project command. The
// description is JSON-quoted YAML, so it cannot add frontmatter keys.
func renderPrompt(item tc.PackItem) (string, []byte, error) {
	name, err := tc.PromptName(item)
	if err != nil {
		return "", nil, err
	}
	var out bytes.Buffer
	out.WriteString("---\n")
	if description := strings.TrimSpace(item.Description); description != "" {
		var quoted bytes.Buffer
		encoder := json.NewEncoder(&quoted)
		encoder.SetEscapeHTML(false)
		if err := encoder.Encode(description); err != nil {
			return "", nil, fmt.Errorf("%w: prompt %q description cannot be encoded", tc.ErrInvalid, item.Name)
		}
		out.WriteString("description: ")
		out.Write(quoted.Bytes()) // Encode ends the line
	}
	out.WriteString("disable-model-invocation: true\n---\n\n")
	out.WriteString(strings.TrimSpace(item.Body) + "\n")
	return commandsDir + name + ".md", out.Bytes(), nil
}
