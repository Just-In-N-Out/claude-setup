## Architecture and request contract

Read-only HTML routes, no public/generated OpenAPI change:

- `GET /admin/library?q=&kind=&category=&tag=&tool=&page=`: labeled GET form, stable URL/bookmark/back behavior, tiles and count, 50 rows per page, previous/next links carrying all filters.
- `GET /admin/library/items/{itemId}`: UUID row identity, immutable version detail, no user-controlled paths/files. Add a `back` query only as server-generated encoded filter values, not an arbitrary return URL; simplest detail has `Back to library` and browser Back restores the filtered URL.
- Admin home has a `Library` link. Keep `packs.go` byte-identical; reuse its package-local styles/header writer without editing it. The catalog links back to admin and Packs.

### Filter semantics (reversible, explicit)

Single selection per dimension. Empty means Any. Dimensions combine with AND. `kind` must pass current `pack.Kind.Valid()`, `tool` current `library.Tool.Valid()`. Category/tag use the loader's lowercase-dashed slug grammar (at most 64 runes). Unknown well-formed category/tag yields a valid empty result, not an error. Text is trimmed Unicode, valid UTF-8, at most 200 runes, no NUL. Case-insensitive literal substring over **name and description** only; `%`, `_`, `\\`, quotes and SQL-looking text are literal, not SQL/LIKE syntax. Blank text matches all. Reject duplicate recognized keys, malformed encoding, bad/negative/noninteger page, invalid enum/slug or over-limit text with 400. Page default 1; cap at 100000 to avoid overflow/resource abuse; pages beyond result count show a recoverable empty page with first-page/clear links. Fixed stable order `(kind,name,version,id)`; version is labeled, not silently semver-ranked. Facets come from global library metadata before active filters so options do not disappear; kind labels derive from `pack.Kinds()` and tools from the three existing library Tool constants.

### Proposed types and data flow

New `internal/library/catalog.go` owns small read models and `Reader`, separate from loader `Store`. `Summary` includes row ID and all tile/filter metadata, excluding Body/Example. `Detail` embeds `Item` plus ID. `Filter{Query,Kind,Category,Tag,Tool,Page}` validates independently of HTTP. `Catalog{Items,Categories,Tags,Total,Page,PageSize}` supports stable pagination. Postgres `ListLibrary` authorizes and fetches metadata only; filter/count/page in memory over bounded metadata (no bodies). `GetLibraryItem` authorizes and selects one body's fields by UUID. No global cache initially; do not cache authorization or tenant-specific data. If measured metadata history growth makes this fail, stop for a measured SQL-filter/index follow-up rather than silently adding a schema or truncating data.

Global content is intentionally visible to **admins of both tenants**. Negative isolation means tenant-owned `pack_items`/`pack_version_items`, users, assignments and audit data never enter results; it does not mean a shared library row must return 404 to tenant B. Reader still requires a real current admin in matching tenant context, including direct store calls; missing/mismatched context and nonexistent user fail closed.

### Rendering and preview safety

- Reuse `html/template`, buffer before writing, `handler.randomHex(16)`, `writeHTMLPage`, existing restrictive `adminCSP`. All metadata/example/source remain plain strings autoescaped by templates.
- A single preview function is the **only** place allowed to create `template.HTML`, and only from the pinned parser's output after disabling raw HTML and rendering **all** links/autolinks/images as text. No `WithUnsafe`, arbitrary attributes, custom HTML, JS, iframe, DOM `innerHTML` or dependency executing content. No syntax highlighting, outbound fetch, MCP connection, shell, file include or tool invocation.
- Markdown skill/agent/prompt bodies get rendered paragraphs/headings/lists/code/emphasis. Config/MCP bodies are displayed as escaped pre/code preserving the source; do not recursively pretty-print attacker-controlled JSON into an unbounded temporary buffer. Examples remain escaped readable text in their own labeled Example section.
- Raw `<script>`, `<iframe>`, form/style/SVG/event handlers, javascript/data/entity-encoded/protocol-relative links and remote images must not become active HTML/resources. Restrictive CSP is defense in depth, not the sanitizer. Never weaken it for previews.
- Bounds are enforced before parsing, even if a fake/store corruption bypasses the loader: body/example at their library bounds, rendering output bounded to 1 MiB; any failure produces a safe 500 `RENDER_FAILED`, no partial unsafe HTML. Preview is not cached and never logs raw content.

### UX state contract

Header → heading/description → labeled search/filters → Apply filters/Clear filters → result count → tiles → pagination. Each tile: kind/name/version/description/category/tags/declared-supported tools/unique detail link. “Supported tools” means loader-declared support, not quality-gate attestation.

Detail: kind/name/version → description/category/tags/tools → Example → Rendered preview → source disclosure (`details/summary`, escaped source), back to library. package library

import (
    "context"
    "slices"
    "strings"
    "unicode/utf8"

    "github.com/LeornaAI/leorna-control-plane/internal/pack"
    "github.com/LeornaAI/leorna-control-plane/internal/store"

const CatalogPageSize = 50

type Filter struct {
    Query string
    Kind pack.Kind
    Category string
    Tag string
    Tool Tool
    Page int
}

func (filter Filter) Normalize() (Filter, error) {
    filter.Query = strings.TrimSpace(filter.Query)
    if !validText(filter.Query) || utf8.RuneCountInString(filter.Query) > 200 ||
        (filter.Kind != "" && !filter.Kind.Valid()) ||
        (filter.Tool != "" && !filter.Tool.Valid()) ||
        (filter.Category != "" && !validSlug(filter.Category)) ||
        (filter.Tag != "" && !validSlug(filter.Tag)) ||
        filter.Page < 0 || filter.Page > 100000 {
        return Filter{}, ErrInvalid
    }
    if filter.Page == 0 { filter.Page = 1 }
    return filter, nil
}

type Summary struct {
    ID string
    Kind pack.Kind
    Name string
    Version string
    Category string
    Tags []string
    Tools []Tool
    Description string
}

type Detail struct {
    ID string
    Item
}

type Catalog struct {
    Items []Summary
    Categories []string
    Tags []string
    Available int
    Total int
    Page int
    PageSize int
}

type Reader interface {
    ListLibrary(context.Context, store.Principal, Filter) (Catalog, error)
    GetLibraryItem(context.Context, store.Principal, string) (Detail, error)
}

// SelectCatalog operates only on metadata; it never parses bodies or executes content.
func SelectCatalog(items []Summary, filter Filter) (Catalog, error) {
    filter, err := filter.Normalize()
    if err != nil { return Catalog{}, err }
    out := Catalog{Available: len(items), Page: filter.Page, PageSize: CatalogPageSize,
        Items: []Summary{}, Categories: []string{}, Tags: []string{}}
    categories, tags := map[string]bool{}, map[string]bool{}
    matches := make([]Summary, 0, len(items))
    query := strings.ToLower(filter.Query)
    for _, item := range items {
        categories[item.Category] = true
        for _, tag := range item.Tags { tags[tag] = true }
        if filter.Kind != "" && item.Kind != filter.Kind { continue }
        if filter.Category != "" && item.Category != filter.Category { continue }
        if filter.Tag != "" && !slices.Contains(item.Tags, filter.Tag) { continue }
        if filter.Tool != "" && !slices.Contains(item.Tools, filter.Tool) { continue }
        if query != "" && !strings.Contains(strings.ToLower(item.Name), query) &&
            !strings.Contains(strings.ToLower(item.Description), query) { continue }
        matches = append(matches, item)
    }
    for value := range categories { out.Categories = append(out.Categories, value) }
    for value := range tags { out.Tags = append(out.Tags, value) }
    slices.Sort(out.Categories)
    slices.Sort(out.Tags)
    slices.SortFunc(matches, func(a, b Summary) int {
        for _, pair := range [][2]string{{string(a.Kind), string(b.Kind)},
            {a.Name,b.Name}, {a.Version,b.Version}, {a.ID,b.ID}} {
            if result := strings.Compare(pair[0],pair[1]); result != 0 { return result }
        }
        return 0
    })
    out.Total = len(matches)
    start := (filter.Page-1)*CatalogPageSize
    if start < len(matches) {
        out.Items = matches[start:min(start+CatalogPageSize,len(matches))]
    }
    return out, nil
}

var _ library.Reader = (*Store)(nil)

func (database *Store) ListLibrary(ctx context.Context, actor store.Principal, filter library.Filter) (library.Catalog,error) {
    normalized,err:=filter.Normalize()
    if err!=nil { return library.Catalog{},err }
    tx,admin,err:=database.beginOrg(ctx,actor,false)
    if err!=nil { return library.Catalog{},err }
    defer func(){ _=tx.Rollback(ctx) }()
    if !admin { return library.Catalog{},org.ErrForbidden }
    rows,err:=tx.Query(ctx,`SELECT id,kind,name,version,category,tags,tools,description FROM library_items`)
    if err!=nil { return library.Catalog{},orgError(err) }
    items:=make([]library.Summary,0)
    for rows.Next() {
        var item library.Summary
        var tools []string
        if err:=rows.Scan(&item.ID,&item.Kind,&item.Name,&item.Version,&item.Category,&item.Tags,&tools,&item.Description); err!=nil {
            rows.Close()
            return library.Catalog{},orgError(err)
        }
        for _,tool:=range tools { item.Tools=append(item.Tools,library.Tool(tool)) }
        items=append(items,item)
    }
    err=rows.Err()
    rows.Close()
    if err!=nil { return library.Catalog{},orgError(err) }
    if err:=tx.Commit(ctx); err!=nil { return library.Catalog{},orgError(err) }
    if err:=ctx.Err(); err!=nil { return library.Catalog{},err }
    return library.SelectCatalog(items,normalized)
}

func (database *Store) GetLibraryItem(ctx context.Context, actor store.Principal, id string) (library.Detail,error) {
    if !validUUID(id) { return library.Detail{},store.ErrNotFound }
    tx,admin,err:=database.beginOrg(ctx,actor,false)
    if err!=nil { return library.Detail{},err }
    defer func(){ _=tx.Rollback(ctx) }()
    if !admin { return library.Detail{},org.ErrForbidden }
    var item library.Detail
    var tools []string
    err=tx.QueryRow(ctx,`SELECT id,kind,name,version,category,tags,tools,description,example,body FROM library_items WHERE id=$1`,id).
        Scan(&item.ID,&item.Kind,&item.Name,&item.Version,&item.Category,&item.Tags,&tools,&item.Description,&item.Example,&item.Body)
    if err!=nil { return library.Detail{},orgError(err) }
    for _,tool:=range tools { item.Tools=append(item.Tools,library.Tool(tool)) }
    if err:=tx.Commit(ctx); err!=nil { return library.Detail{},orgError(err) }
    return item,nil
}

func libraryFilter(r *http.Request) (library.Filter,error) {
    if len(r.URL.RawQuery)>4096 { return library.Filter{},library.ErrInvalid }
    values,err:=url.ParseQuery(r.URL.RawQuery)
    if err!=nil { return library.Filter{},library.ErrInvalid }
    for _,key:=range []string{"q","kind","category","tag","tool","page"} {
        if len(values[key])>1 { return library.Filter{},library.ErrInvalid }
    }
    page:=1
    if value,exists:=values["page"]; exists {
        page,err=strconv.Atoi(value[0])
        if err!=nil || page<1 { return library.Filter{},library.ErrInvalid }
    }
    return (library.Filter{Query:values.Get("q"),Kind:pack.Kind(values.Get("kind")),
        Category:values.Get("category"),Tag:values.Get("tag"),Tool:library.Tool(values.Get("tool")),Page:page}).Normalize()
}

func libraryURL(filter library.Filter,page int) string {
    values:=url.Values{}
    for _,pair:=range [][2]string{{"q",filter.Query},{"kind",string(filter.Kind)},
        {"category",filter.Category},{"tag",filter.Tag},{"tool",string(filter.Tool)}} {
        if pair[1]!="" { values.Set(pair[0],pair[1]) }
    }
    if page>1 { values.Set("page",strconv.Itoa(page)) }
    if len(values)==0 { return "/admin/library" }
    return "/admin/library?"+values.Encode()
}

        return

    if err!=nil { handler.libraryResult(w,r,err); return }
    if filter.Category!="" && !slices.Contains(catalog.Categories,filter.Category) { catalog.Categories=append(catalog.Categories,filter.Category); slices.Sort(catalog.Categories) }
    if filter.Tag!="" && !slices.Contains(catalog.Tags,filter.Tag) { catalog.Tags=append(catalog.Tags,filter.Tag); slices.Sort(catalog.Tags) }

        data.Message="No library items match these filters. Clear filters or return to the first page."

func (handler *Handler) libraryResult(w http.ResponseWriter,r *http.Request,err error) {
    switch {
    case errors.Is(err,library.ErrInvalid):
        handler.libraryNotice(w,r,http.StatusBadRequest,"Invalid library filters.")
    case errors.Is(err,org.ErrForbidden):
        handler.writeProblem(w,r,http.StatusForbidden,"ADMIN_REQUIRED","Administration rights are required")

    }
    handler.writeHTMLPage(w,nonce,status,&page)
}

var errLibraryPreview = errors.New("library preview could not be rendered")
const maxLibraryPreviewBytes = 1 << 20

type libraryPreviewWriter struct { bytes.Buffer }
func (writer *libraryPreviewWriter) Write(data []byte) (int,error) {
    if writer.Len()+len(data)>maxLibraryPreviewBytes { return 0,errLibraryPreview }
    return writer.Buffer.Write(data)
}

type libraryInertNodes struct{}
func (libraryInertNodes) RegisterFuncs(register renderer.NodeRendererFuncRegisterer) {
    register.Register(ast.KindLink,libraryInertInline)
    register.Register(ast.KindImage,libraryInertInline)
    register.Register(ast.KindAutoLink,libraryInertAutoLink)
    register.Register(ast.KindRawHTML,libraryOmitHTML)
    register.Register(ast.KindHTMLBlock,libraryOmitHTML)
}
func libraryInertInline(_ util.BufWriter,_ []byte,_ ast.Node,_ bool) (ast.WalkStatus,error) {
    // No element/URL emitted; normal child text/emphasis/code remains escaped by goldmark.
    return ast.WalkContinue,nil
}
func libraryInertAutoLink(writer util.BufWriter,source []byte,node ast.Node,entering bool) (ast.WalkStatus,error) {
    if entering {
        if _,err:=io.WriteString(writer,html.EscapeString(string(node.(*ast.AutoLink).Label(source)))); err!=nil { return ast.WalkStop,err }
    }
    return ast.WalkSkipChildren,nil
}
func libraryOmitHTML(_ util.BufWriter,_ []byte,_ ast.Node,_ bool) (ast.WalkStatus,error) {
    return ast.WalkSkipChildren,nil
}

func renderLibraryPreview(item library.Item) (template.HTML,error) {
    if len(item.Body)>pack.MaxBodyBytes || len(item.Example)>library.MaxExampleBytes ||
        !utf8.ValidString(item.Body) || !utf8.ValidString(item.Example) ||
        strings.ContainsRune(item.Body,0) || strings.ContainsRune(item.Example,0) { return "",errLibraryPreview }
    if item.Kind==pack.KindConfig || item.Kind==pack.KindMCPTemplate {
        safe:="<pre><code>"+html.EscapeString(item.Body)+"</code></pre>"
        if len(safe)>maxLibraryPreviewBytes { return "",errLibraryPreview }
        return template.HTML(safe),nil // generated constant wrapper plus escaped text only
    }
    markdown:=goldmark.New(goldmark.WithRendererOptions(renderer.WithNodeRenderers(util.Prioritized(libraryInertNodes{},100))))
    var safe libraryPreviewWriter
    if err:=markdown.Convert([]byte(item.Body),&safe); err!=nil { return "",errLibraryPreview }
    return template.HTML(safe.String()),nil // parser-generated inert markup; sole audited trusted-HTML boundary
}
