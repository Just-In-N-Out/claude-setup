# Clipboard delivery on WSL

Back up the current clipboard before replacing it. Write the exact UTF-8 Bricks payload and compare a readback byte-for-byte; parsing JSON alone does not establish completeness. Keep a payload file as a fallback.

PowerShell interop normally supports Set-Clipboard. If it fails with `UtilBindVsockAnyPort` even after a permitted escalation, WSLg may still expose a Linux clipboard through `$DISPLAY` and `/tmp/.X11-unix/X0`. Reading the original Windows text there does not prove reverse synchronization works. Use `xsel --clipboard --output` to back it up, but require Windows-side readback or a user-confirmed Windows paste before claiming Windows delivery. If xsel is absent, a verified official Ubuntu package may be extracted into the task folder without sudo; do not install unverified binaries.

Run `xsel --clipboard --input --nodetach < payload.json` in a persistent exec session. Keep that owner session alive while Justin pastes. In a separate tool call, read `xsel --clipboard --output` to a file and compare its bytes and SHA-256 with the payload, then repeat after unrelated work. Do not close the owner after successful verification.

Observed 2026-10-28: a detached writer passed an immediate 302,642-byte readback, but a later command got only 48,000 bytes. A persistent foreground owner retained the complete payload across commands. Do not infer a clipboard-manager limit or its cause from this alone, or claim that same-command readback proves a usable paste. Linux readback, Windows delivery and a successful paste into Bricks are separate evidence. Justin reported that Windows received nothing despite repeated complete Linux readbacks; this method was not a successful Windows delivery.

When Windows interop is unavailable and host delivery is unproved, stop claiming the clipboard is ready. Prepare a standalone HTML file embedding the exact payload, with a user-clicked `navigator.clipboard.writeText` button and a selected-text fallback. Save it in the Windows Downloads folder through an authorized write, verify the file bytes, and tell Justin the exact filename and button. Keep the button result and actual Bricks paste unconfirmed until observed.
