# Core constraints (companion to rules-summary.md)

Read for architecture, fonts, media, URL safety or fixture/build changes. CLAUDE.md wins; see SKILL.md pitfalls and relevant HANDOFF/ledger for exact probes and decisions.

- Figma→editable Bricks2.3.9, ExampleBricks target; v1 `~/Desktop/figmaplugin` read-only. Spec `docs/specs/2026-10-06-v2-design.md`.
- extract→normalise→understand→style→adapt→emit; only plugin extract calls Figma, pure Node core. Never mutate earlier stages, change type after creation or double-convert. Typed CSS `{bp,state,part,decls,origin}` until emit, no CSS regex. Native Bricks controls first, otherwise one _cssCustom per element.
- General structure/layout/constraints/fills/proportions/repetition/clipping, not sample names/IDs/text/pixels/colours/fonts/order. Names hints only; generic variations/fallback, ask before special cases.
- Only adapt/rules writes bp styles: named purpose/origin/decision, explicit collision overrides covering narrower tiers. Sizes PageFacts, widths ctx.layout. Only bp changes except exact-design-width fluid clamp; explicit restores for cascade. Shared style purpose class. Phone copies only understand/phone.ts; drawn phones fits/shows only.
- Shared breakpoints/media/gutters, deterministic IDs, ~300lines/file. Scripts/CSS marker classes, never renamed Bricks IDs. Emitters from reference/bricks/*.json; unsupported native keys need authoritative schema/sample/roundtrip.
- Bricks sourceUrl=site or grey media; Block100% needs width:auto and left/right. Flow controls only section/container/block/div; elsewhere _flexDirection/_gap. Never _alignSelf:stretch; flex-basis px. brxe max-width100%; Blocks wrap≤767.
- Weights whole hundreds, no raw ranges/nonnumeric paste weights; intermediate OS/2 yields to style name. Resolve inherited classes/no redundant weights. Same-family/slant usable variable covers inclusive statics; dropping variable needs one spanning full range. Name supplied/unknown, never promise physical font/substitution.
- Google200 confirms only covering family/weight/slant, exact site coverage wins. Executable typed scanner handles comments/repeated descriptors (last supported numeric; only absence defaults400); unsupported present stays unconfirmed. Projection retains strict duplicate/escape/raw/important guards. Ranges emit covered requested whole weights only; statics unchanged. Literal syntax before normalization; preserve valid multiword keywords/Unicode/opposite quotes/oblique angles. No extra requests, supplied=pasted faces. Chrome executable reader differs from Bricks raw reader; SKILL has exact escape/comment controls.
- WP stand-ins follow source/answers, not expectations. Font-faces endpoint returns all families: filter family parent in ui/site-fonts.ts.
- Media L1A/L2A/L3A safe-image/video transmitted slug; metadata may override filename. Unattached owns /slug/, attached full parent path. Only cache-owned active-WP-picture media moves, inline reads only. Permission recheck+POST+exact-ID GET inside per-ID queue. Verify changed slug/same ID+file/old path free; never blindly retry uncertain POST.
- Q1A finite deterministic unprotected-image alternatives reserved before one repair POST. Reindex actual readback/full attached paths across all protected original/candidate addresses, not requested slug. Current occupancy beats freed history; verified moves separately once/ID, aliases/reoccupation included. Unexpected protected destination plain, not retry. Matching/counts/cancellation otherwise unchanged.
- Moves do not repair saved links or guarantee redirects: re-convert/re-paste, matched canonical href only; blocked target plain. Opaque positive attachment ID unknown/plain navigation; direct docs/videos valid.
- Cancel survives run.done(): check ownership after every finish await (video too), before copy/rerun/notes/errors/busy. Stale callback never unlocks replacement. Sent writes settle/cache, no new repair or cancelled paste.
- assertPayload after core and final assets/fonts/relinking; invalid never copies. New URL sources use safeUrl/fileAddressKind. Positive fixtures six-letter IDs/reciprocal trees; fix fixtures, not validation.
- SES rejects import followed by (, //, /*, or HTML-comment delimiters anywhere, comments included. Never end comment with import. Node .ts erasable only. Fixture text family, not fontFamily. Sensitivity probes restore exact bytes.
- **An Image standing for an empty box with a CSS background is Bricks' `tag: "figure"` Image, never a bare `img`** (photo-box-image planner, Chrome 156: a bare img with the box's padding removed drew 500 px against 505.05, since flex-shrink weighs the content-box base). Inside the figure the `img` can't be `position: absolute` (Bricks' layered `:where(.brxe-image) img{position:static !important}` beats any unlayered `!important`). What draws exactly: the figure `display: grid` with `minmax(0, 1fr)` tracks, `height: auto` (Bricks' `.tag{height:fit-content}` stops a row's stretch), zero margins (a figure's own are `1em 40px`), `overflow: clip` under a radius; the img `contain: size; place-self: stretch; width/height: auto`, margins minus the padding, `object-position` always written (a background starts at 0% 0%). A bordered round box leaves a corner hairline: keep it a Block.
