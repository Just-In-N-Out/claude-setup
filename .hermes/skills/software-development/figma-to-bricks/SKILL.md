# Figma to Bricks v2 (FigmaToBricksV2)

Justin's Figma plugin that converts any Figma design into a Bricks (WordPress) paste. Main folder: `~/Documents/FigmaToBricksV2`, branch `main`, private GitHub `Just-In-N-Out/FigmaToBricksV2`. Figma loads the main folder's `dist/`.

The project's standing rules and compact Status are in the main folder's `CLAUDE.md` (not in git); feature history is in HANDOFF and plan ledgers. Hermes sessions start in `~`, so it never auto-loads; this skill makes sure it's read and adapts its Claude Code worktree steps to Hermes. When this skill and that `CLAUDE.md` disagree, `CLAUDE.md` wins.

**The standard for every paste (Justin, 2026-11-13): both tools build it like a skilled Bricks builder made it by hand, easy for a Bricks pro to change** — Section → Container → Blocks, Bricks' own elements, labelled boxes, shared purpose-named classes (short site prefix, `bd-heading-1`), settings before custom CSS, palette colours, Bricks' own behaviour before Code, editable content in fields, looks still true (exact wins over clean). The six points are at the top of `CLAUDE.md` "Decisions the user made"; every plan says how it meets them and every review asks "would a Bricks pro find this logical and easy to change?".

**Every change goes into the plugin (Justin, 2026-10-29: "every single change needs to be inside the plug-in, not just for copy-pasting purposes").** A fix found on one site's paste (e.g. the B-Dry copy of bdryswi.com) is also planned as a general plugin change so every converted website gets it; a paste-only patch is at most a stop-gap beside the plugin job, never the whole answer. A planner whose fix is paste-only names the plugin code that produced or would produce the same output (file:line) and the general rule, or says plainly why the plugin can't be involved (e.g. a look Figma can't express). **But prove it first** (Justin, 2026-10-29: "How do I know my plugin has these three issues? … stop them until we test the plugin"): a problem seen on a hand-built paste becomes a plugin job only once a real plugin conversion shows it (a replay or snap of a Figma file, or the plugin's own paste); until then it is recorded as a suspicion, not planned.
