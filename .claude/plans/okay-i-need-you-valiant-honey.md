# FAQ answers for the live site (darksalmon-badger-335429.hostingersite.com)

## Context

Justin asked for FAQ questions for each page of the live site that has an FAQ. I read all 10 published pages
(LiteSpeed cache skipped). Seven have an FAQ section: **Home, Contact, and the five service pages**. The
About, Services and Gallery pages have none.

On each FAQ, the designer's questions are already there and **only the first answer is written**. Every other
item still says `Answer to "…": write it in Bricks.` **Google sees those placeholders too.** Bricks builds the
page's FAQ search data from the accordion (its "FAQ schema" setting), so the placeholders go into it as written.
Once the answers are typed in Bricks and the cache is purged, the search copy updates by itself.

The answers below use only facts already on the site: hours, phone numbers, brands, the 10 states, the 200+ mile
radius, 1″–15″ rods and 10,000 PSI. A line in **[brackets]** is a fact the site doesn't give, so the client must
fill it in or confirm it before it goes up.

Nothing in the plugin or the repo changes. On approval, I give this list in chat, ready to paste.

## Steps for Justin in Bricks (each page)

1. Open the page with **Edit with Bricks**.
2. In the FAQ, click a question to open it. Click its answer ("Answer to … write it in Bricks"), select all the
   words, and paste the new answer.
3. Repeat for each placeholder, then **Cmd+S**.
4. WordPress admin bar → LiteSpeed (diamond) → **Purge All**.
5. To add an extra question, right-click an FAQ item in the Structure panel → **Duplicate**, then change its words.
