On 2026-10-29 five B-Dry paste fixes (animation speed, the 60 Years circle, a picture size, a button border, the hero logo) were planned as paste-only patches. Justin: "I don't want it to be specific to this website. I want it for every single website", then "make it a note for future agents that every single change needs to be inside the plug-in, not just for copy-pasting purposes."

**Why:** the plugin converts any designer's file; a fix that lives only in one paste helps no other site.

**How to apply:** every reported problem gets a plugin job (general rule, Full pipeline) — a paste patch may run beside it as a stop-gap when he wants the page fixed sooner. Briefs say this; planners of paste-only work must name the plugin code and the general rule. Rule also in the figma-to-bricks skill and pending for CLAUDE.md. See [[bdry-home-copy]], [[deliverable-first]].

**Then, later on 2026-10-29:** three plugin jobs started from the B-Dry hand-built paste's problems (entrance timing, colourless borders, frozen picture sizes) were stopped by Justin: "How do I know my plugin has these three issues? … stop them until we test the plugin, and then we'll see." So: a fix goes into the plugin, but only after a real plugin conversion shows the problem; a hand-built copy's symptom is a suspicion until then (the border planner had already found no colourless border in any fixture).

**Interaction clues (2026-10-30):** Justin expects obvious intended interactions to be identified from the drawing and structure, even when the debug export has empty reactions/animations. In the DJ Trees landing-page discussion he pointed out the testimonial's active bar and two dots as a swipe-slider cue, then said "you should be able to figure it out and have identified the animation." The supplied snapshot confirms one placeholder review with those three pager shapes and no recorded interaction. Flag such candidates proactively; do not require a working prototype or video before recognising the likely intent. Distinguish inferred interaction intent from recorded or observed behavior: dots alone do not establish autoplay, timing, or missing slide content, and this correction does not authorise unrelated invented motion.
