name: Rise Student Hiring Platform

type: project

Rise is a passive talent matching platform — students upload profiles once, companies search/filter to find candidates. No traditional job applications.

**Why:** Building a production-quality UI prototype that will be handed off to a developer to wire up to a NestJS backend.

**How to apply:** All work is frontend-only. No backend, no real auth. Use mock data everywhere. Brand palette is teal-centric (teal-dark, teal-brand, teal-electric, teal-white). No UI libraries — all components built from scratch. ~80 files across 20+ routes.
